# 摘要
网易gdc2025，在七日世界中实现了大场景高效的全局光照探针数据压缩和推理。
主要解决了Tod数据压缩、手电筒光源的动态光照数据压缩和漏光问题，最后提出了一个结合屏幕空间光照的管线将其统合起来。
# 神经Tod数据压缩
探针在场景中的分布以“探针砖”的形式出现，即一个立方体中均匀分布着多个探针。一个探针砖由$5\times5\times5$个子探针组成，每个探针使用二阶球谐函数保存，考虑到Tod，一共需要保存24套探针数据。
本文方法是使用一个神经网络对每个探针砖进行压缩。文中使用了一个轻量级的MLP进行推理，只有一个隐藏层和一个激活函数。网络输出12个球谐系数，经测试隐藏层神经元数量需要$\geq12$。
对于每个探针，携带一个特征向量(float1)，然后取归一化空间位置和归一化时间，进行PE之后和特征拼接在一起输入网络。

# 神经手电筒光照数据压缩
游戏中考虑了手电筒这个动态光源造成的全局光照影响，因此对每个探针砖烘焙了手电筒在砖内不同的空间位置和方向所造成的全局光照结果。
由于手电筒的位置和朝向不同会导致产生高频信息，因此用于输入网络的特征不能仅保存在每个探针中，相比于用于压缩Tod的特征立方体，压缩手电筒使用了三个三平面特征网格。对于手电筒位置和方向$(x,y,z,\theta,\phi)$，采用了$xy,yz,xz,x\phi,y\phi,z\phi,x\theta,y\theta,z\theta$共九个平面进行特征保存。
![](37.png)
由于手电筒可能在砖外面，本文设计了一套UV映射函数来给砖内和砖外的手电筒分配特征网格点的UV映射方案。
对于MLP而言，采用了一个相比于Tod压缩更大的MLP。
# 室内外漏光解决
为了解决室内外的漏光情况，不然室外的光漏到室内。（不考虑室内和室内的情况）本文让每个探针保存一个调整过的sdf数值，表征其到最近室内外分隔点(隔绝室内外的墙体)的距离。对于着色点，通过插值其相邻探针的sdf数值得到一个值，事实上，着色的时候，我们需要关心的这个点的sdf数值的正负性。
在砖内均匀撒下采样点，如果采样点在室外置为+1，在室内置为-1，通过逆三线性插值和机器学习的算法就可以对探针上保存的sdf数值进行拟合。
![](38.png)
接下来解决烘焙时区分室内点和室外点的问题。一个想法是，通过将物体材质设定成为白色，并移除所有光源，只保留天空光源，烘焙所有采样点的球谐系数，通过恢复的光的亮度进行筛选，亮度太低为室内点。
但这样会导致设置需要手动调整这个亮度阈值，否则在门边的点会发生误判。
本文采用了一个机器学习的方法，构建一个大网络，用于判断一个点是室内点还是室外点，通过人工标注进行打标签。网络接受一个球谐输入，输出其位于室内还是室外的标签。这个大网络是预训练的，用于正式训练时对采样点做蒸馏。
![](39.png)
只使用网络预测的sdf来进行着色的话，会因为预测的不准确导致一定程度上的漏光。因此要将着色点向法线方向和视线方向进行一定的偏移。
还有一个问题在于室内和室外过渡太生硬，所以让网络多预测一个平滑度的值，让sdf值除以这个权重之后再算一个sigmoid得到最终的sdf权重。
